PUT YOUR BANANA KML FILES HERE
==============================

Naming convention (REQUIRED):
  The filename must contain the survey/confirmation date so the system
  knows which 12-month window to download from Google Earth Engine.

  Format:  <plot_number>_<day><month><year>.kml

  Examples:
    1_3aug2023.kml
    2_15jan2024.kml
    12_20sep2023.kml
    plot5_7mar2024.kml

  Supported date formats in filename:
    3aug2023      → 3 August 2023
    15jan2024     → 15 January 2024
    2023-08-03    → 3 August 2023
    20230803      → 3 August 2023

What happens with the date:
  GEE download window = anchor_date − 12 months  →  anchor_date + 12 months
  This captures a full annual cycle of confirmed banana presence.

State tagging (optional):
  If the filename contains a state name, it is auto-detected:
    maharashtra_1_3aug2023.kml  → state = Maharashtra
    jalgaon_plot2_15jan2024.kml → state = Maharashtra  (jalgaon → Maharashtra)

  All Jalgaon plots are automatically tagged as Maharashtra.
